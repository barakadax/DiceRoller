# Dice roller
Node JS React native android/ios application that let you decide 1-9 dices to roll<br>

## How to run:
```shell
# For android
npm start android

# For ios
npm start ios
```

## How to install dependencies:
```shell
npm install
```

## Commands to check if device is connected and is authorized to debug:
```shell
adb kill-server
adb start-server
adb devices
```
